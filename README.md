# Мен туралы ақпарат

Учебный пример на Python и PyQt5 с интерфейсом на казахском языке. Введи имя, группу и специальность, затем нажми **«Көрсету»** («Показать»). Если какое-либо поле пустое, форма попросит заполнить все поля.

## Запуск

Установи [uv](https://docs.astral.sh/uv/getting-started/installation/), затем выполни в терминале:

```sh
git clone https://github.com/Yerlan110110/pyqt5-about-me.git
cd pyqt5-about-me
uv run app.py
```

При первом запуске uv установит PyQt5. После этого откроется окно.

## Как устроен код

В [app.py](app.py) функция `build_window()` собирает окно. Каждый вызов `form.addRow(...)` добавляет строку формы. Если передать два элемента, подпись появится слева, а поле ввода справа.

Строка `button.clicked.connect(show_info)` связывает кнопку с функцией `show_info()`. При нажатии функция читает поля, убирает пробелы по краям и показывает результат под кнопкой.
